## 🔧 Преимущества такой структуры

### ✅ **Модульность**
- Каждая фича — независимый модуль
- Легко добавлять/удалять функциональность
- Чёткое разделение ответственности

### ✅ **Масштабируемость**
- Легко расширять приложение
- Новые разработчики быстро ориентируются
- Минимальные конфликты при работе в команде

### ✅ **Поддержка**
- Легко находить нужный код
- Простые обновления отдельных частей
- Чёткие границы между слоями

### ✅ **Тестирование**
- Каждый модуль можно тестировать отдельно
- Хуки легко мокать
- Компоненты изолированы

## 📄 Пример реализации ключевых частей

### 🔥 `src/core/hooks/useNavigation.ts`
```tsx
// Единая точка навигации для всего приложения
import { useState } from 'react';

export const useNavigation = () => {
  const [currentView, setCurrentView] = useState('public');
  const [currentPanel, setCurrentPanel] = useState('public');

  const navigateTo = (view: string, panel: string) => {
    setCurrentView(view);
    setCurrentPanel(panel);
  };

  const goBack = () => {
    // Логика возврата
  };

  return {
    currentView,
    currentPanel,
    navigateTo,
    goBack
  };
};
```

### 🔥 `src/types/index.ts`
```ts
// Единая точка экспорта всех типов
export * from './tournament';
```

### 🔥 `src/components/ui/LogoSelector.tsx`
```tsx
// Переиспользуемый компонент выбора логотипа
import React from 'react';
import { PopoutWrapper, List, Cell } from '@vkontakte/vkui';
import { Icon28Users3Outline } from '@vkontakte/icons';

interface LogoSelectorProps {
  availableLogos: string[];
  selectedLogo: string;
  onLogoSelect: (logo: string) => void;
  show: boolean;
  onClose: () => void;
}

export const LogoSelector = ({ 
  availableLogos, 
  selectedLogo, 
  onLogoSelect, 
  show, 
  onClose 
}: LogoSelectorProps) => {
  return (
    <PopoutWrapper onClick={onClose} closing={!show}>
      <List>
        {availableLogos.map(filename => (
          <Cell
            key={filename}
            onClick={() => onLogoSelect(filename)}
            before={<Icon28Users3Outline />}
          >
            {filename.replace('.png', '')}
          </Cell>
        ))}
      </List>
    </PopoutWrapper>
  );
};
```

### 🔥 `src/features/teams/views/TeamRosterView.tsx`
```tsx
// Чистая бизнес-логика без лишнего кода
import React from 'react';
import { TeamRoster } from '../components/TeamRoster';
import { useTeams } from '../../hooks/useTeams';
import { useNavigation } from '../../../core/hooks/useNavigation';

export const TeamRosterView = ({ tournament, user }) => {
  const { players, loading, handleAddPlayer, handleDeletePlayer } = useTeams(tournament, user);
  const { navigateTo } = useNavigation();

  if (loading) return <div>Loading...</div>;

  return (
    <TeamRoster
      players={players}
      onAddPlayer={() => navigateTo('main', 'add-player')}
      onDeletePlayer={handleDeletePlayer}
      tournament={tournament}
      user={user}
    />
  );
};
```

## 🚀 Как перейти к новой структуре

### Шаг 1: Создай базовую структуру
```bash
mkdir -p src/{core/hooks,core/utils,types,components/layout,components/ui,features/auth,features/tournaments,features/teams,routes}
```

### Шаг 2: Перенеси существующий код по категориям
- **Firebase config** → `src/core/config/firebase.ts`
- **Типы** → `src/types/`
- **Общие компоненты** → `src/components/`
- **Фичи** → `src/features/`

### Шаг 3: Обнови импорты
Замени все импорты с относительных путей на абсолютные:
```ts
// Было:
import { TeamRoster } from '../../tabs/captain/TeamRoster';

// Стало:
import { TeamRoster } from '@/features/teams/components/TeamRoster';
```

### Шаг 4: Настрой alias в tsconfig.json
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

## 💡 Советы по миграции

1. **Начни с малого** — перенеси сначала `types` и `core/config`
2. **Делай по одному модулю** — не пытайся переделать всё сразу
3. **Тестируй после каждого шага** — убедись, что ничего не сломалось
4. **Используй IDE** — большинство редакторов автоматически обновляют импорты при перемещении файлов
